``sylius_resource_view``
========================

This view is used to render ``Sylius\Resource\Model\ResourceInterface`` entity.

Available variables
-------------------

+---------------+--------------------------------------+
| Variable name | Description                          |
+===============+======================================+
| ``resource``  | The resource which is being rendered |
+---------------+--------------------------------------+
| ``view_type`` | The view type of the resource        |
+---------------+--------------------------------------+
