``ProductType``
===============

+--------------------+----------------------------------------------------------------+
| Identifier         | ``sylius_product``                                             |
+--------------------+----------------------------------------------------------------+
| Class              | ``Netgen\Layouts\Sylius\Parameters\ParameterType\ProductType`` |
+--------------------+----------------------------------------------------------------+
| Valid value        | ID of an existing Sylius product                               |
+--------------------+----------------------------------------------------------------+

This parameter allows to input the ID of an existing Sylius product as its
value.

.. note::

    This parameter type is available only if using Netgen Layouts on top of
    Sylius.
